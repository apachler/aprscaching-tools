# APRS SSID guide

The APRS SSID guide shows the conventional APRS SSID assignments in a panel: `-9` for a mobile, `-10` for an IGate,
`-13` for a weather station and the rest. It is for operators choosing an SSID or reading one.

## Use it

Install the guide and switch it on. The table shows in the Tools app, the packet terminal and the BBS.

## Permissions

| Permission | Why |
|---|---|
| `panel` | Shows the SSID table |
